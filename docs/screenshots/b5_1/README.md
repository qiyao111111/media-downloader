# B5.1 screenshots

Required root PNGs are actual source Qt application/widget captures. Analyzed/8K60 sources use live metadata and thumbnails; Queue state PNGs come from real downloads and Cancel/Retry actions. History reads isolated persisted real records. Logs show actual runtime health, with a separate empty-state capture. Network/403 error images use explicit typed-error injection; invalid URL uses real extraction.

`dpi/` contains actual shown Qt widget captures with synthetic stress metadata. It covers 100/125/150% Qt scaling, two desktop sizes and both languages/themes. These images are layout evidence, not real-download evidence. Matrix details are in `docs/evidence/b5_1/geometry-matrix.json`. Native Windows DPI settings were not changed.

No mockup, generated image or historical B5 screenshot is represented as B5.1 evidence. Source UI images show RC1 because UI acceptance/commit precedes the RC2 version bump. `about-rc2.png` and `rc2/` are actual frozen RC2 package captures. The legacy frozen helper's Settings images are excluded; Settings acceptance uses the category-aware source matrix.
