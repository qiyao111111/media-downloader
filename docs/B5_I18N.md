# B5 Internationalization

Supported: English (`en_US`) and Simplified Chinese (`zh_CN`); persisted compatibility values remain `en` / `zh`.
Both JSON catalogs contain **199 keys**, with identical key sets and formatting placeholders.
`i18n.tr` falls back to English and records a warning on absent keys. A key missing in both languages
returns a friendly generic error, never the internal key. Missing-key tests deliberately exercise this fallback.
Product acceptance must report zero missing keys; the test-created missing key is cleared after its assertion.

The five pages, navigation, menus, buttons, labels, tooltips, statuses, empty states, Settings groups,
Runtime Health, Welcome, About, Help and error dialogs use shared bindings. Live switches update existing widgets.
Technical codec/container values, IDs, formats and credentials remain untranslated itemData/records.
No format expression is reconstructed from a localized label.
Native Qt standard dialog/context-menu Chinese uses the wheel's exact `qtbase_zh_CN.qm`; all other .qm files remain excluded.
Native OS file dialogs may follow the Windows language; titles and filters supplied by the app are translated.
Technical log messages and expanded error details retain original diagnostic language and are redacted.
Unused legacy extension dialogs are not part of the product's five-page flow.

Installer languages: English and Simplified Chinese, selected by Inno; current-user/admin policy is unchanged.
The original GBK Chinese language file, maintained by Zhenghan Yang, is pinned from
[Inno Setup is-6_7_3](https://github.com/jrsoftware/issrc/blob/is-6_7_3/Files/Languages/Unofficial/ChineseSimplified.isl).
SHA256: `7d544b9bb1d142cfa11f2e5d3cc8abe2e55f8e066c5124e3772675aa236e1278`.
Its copyright/maintainer header and provenance accompany `SOURCES/Installer`; no local translation edits.

The added Qt translation's exact official source archive is pinned with SHA256
`021684c1a7937a9fabc3b056a6698ad5978794caf9ac190fd6cc11399e67c014` from
[QtTranslations 6.11.2](https://download.qt.io/archive/qt/6.11/6.11.2/submodules/qttranslations-everywhere-src-6.11.2.tar.xz).
Its source/license materials enter the existing license collector; this does not clear Public Distribution Gate.

Automated coverage: parity/nonempty/placeholder contracts, fallback diagnostics, every bound visible text on both languages,
raw browser/Profile/Proxy/download-options equality, unchanged dynamic selections, statuses and friendly error messages.
Builder callbacks are compared by function and arguments rather than fresh functools.partial object identity.
Final frozen Qt and DPI observations are recorded in B5_RC_VALIDATION.md.
