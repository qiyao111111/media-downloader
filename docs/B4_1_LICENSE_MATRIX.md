## Exact FFmpeg configuration and corresponding-source gap

`-L` was run on this actual binary, not inferred from FFmpeg's usual default. Configuration:
`--enable-version3 --enable-shared --disable-static --pkg-config-flags=--static`,
no `--enable-gpl` / `--enable-nonfree`. **FFmpeg shared DLLs do not mean all external dependencies are dynamic.**
`ffplay.exe` actually ships and is included in scope. Main FFmpeg revision is
`330caae0c1acccd2222edc52a05940c574561ce5`; compiler reports GCC 16.2.0 / crosstool-NG 1.29.0.7_b1a94f6.

GPLv3 section 1/6 and LGPLv3 sections 2/4 require the applicable corresponding-source/combination conditions;
source completeness is not established by pointing to the main repo. The dated BtbN recipes contain
`cargo update cc` in rav1e, so a pinned recipe/repo ref alone does not prove resolved transitive versions.
No publisher binary-specific resolved-source manifest was available in the audited release assets.
Below rows enumerate **actual enable flags**, not all packages in an upstream repository. Exact version/license
matching for these binary-linked portions remains ACTION REQUIRED. Header-only/system integrations may have
different obligations, but their mere enable flag is not treated as proof of a redistributed Windows driver.

## Qt / Python / Deno review boundaries

Qt archive attribution includes Freetype, HarfBuzz, libpng, JPEG-turbo, PCRE2, public-suffix MPL data,
Unicode/CLDR, TIFF/WebP and smaller helpers, as well as unshipped Android/Wayland/examples/tests.
Original copyright/license texts and full archives accompany the RC. Target-specific code inclusion/build
configuration must be matched before marking the aggregate row PASS. LGPL section 4 replacement/debugging
conditions are documented; no code-signature restriction added. A generic LGPL label is not applied to every file.

Microsoft review concerns the **actual Python LICENSE Additional Conditions** and the downstream-protection
requirement for Distributable Code, alongside the Qt wheel's 14.44 redistributables. No Visual Studio purchase
or other entitlement is invented. [Microsoft's redistribution documentation](https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files?view=msvc-170)
is the official reference; installer currently presents the project MIT grant only. Public redistribution blocked
until the applicable downstream terms/provenance are established.

Deno's exact Cargo.lock has 1128 package records, including build/test/other-platform candidates.
It contains V8/v8x records but is not an executable SBOM. The MIT direct license does not cover every
Rust/V8/ICU dependency. Match actual Windows executable inclusion and component-specific notice/source
conditions; legal review for any ambiguous target-specific obligations is required before publication.

Python source includes its own incorporated notices; external PCbuild dependencies are not automatically
present inside the Python main-source archive. Rows marked ACTION REQUIRED keep that distinction explicit.

FFmpeg, dated BtbN recipes, Qt/PySide and Python; `source-provenance.json` supplies URLs and SHA256.
